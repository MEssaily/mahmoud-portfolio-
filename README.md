# Mahmoud Essaily Portfolio

React + Vite portfolio website ready for Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Upload this folder to GitHub.
2. Open Vercel and choose **Add New Project**.
3. Import the GitHub repository.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click Deploy.

## Images
